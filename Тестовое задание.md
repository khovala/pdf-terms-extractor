# Тестовое задание для кандидата

## 1. Описание задачи

Необходимо автоматически извлекать перечни: сокращения; термины и определения из документов.  
Документы изначально без текстового слоя (`pdf` из картинок, сканы документов).

Необходимо извлекать перечни в PostgreSQL с привязкой к документу, чтобы была возможность получать перечни по названию документа.

## 2. Особенности документов

- Разнородное качество сканов.
- Возможное отсутствие искомых разделов.
- Расположение разделов в произвольных местах документа (начало, середина).

## 3. Стек и ограничения

При использовании технологий, работающих на GPU, необходимо учитывать ограничение: **32 ГБ видеопамяти**.  
Решение необходимо обернуть в Docker.

## 4. Отказоустойчивость и возможность рестарта

- При перезапуске сервиса или возникновении ошибок система должна продолжать обработку с учётом уже обработанных документов.
- Нужна оптимизация по уже обработанным данным (избежание повторной обработки).
